## ⚙️ How to make the Live Link visible on your GitHub Repository page

To display the website link at the top right of your GitHub repository:
1. Go to your **GitHub Repository** main page.
2. In the right sidebar, locate the **"About"** section.
3. Click the ⚙️ **Gear icon** next to **About**.
4. In the **Website** field, paste:
   ```
   https://ais-pre-myfhuj3iqskmikrtmtqluu-675285719668.asia-east1.run.app/
   ```
5. In the **Description** field, paste:
   ```
   Ruchita Sahukari — Professional Journalism, The Lit Scroll & Media Communications Portfolio
   ```
6. Click **Save changes**. The clickable live website button will now be displayed prominently in your repository header!

## 🌟 Key Features

1. **Two Distinct Link Modes**:
   - **Public Mode (`/`)**: Read-only, distraction-free dossier designed for employers and newsrooms.
   - **Admin Mode (`/?edit=ruchita`)**: Secret studio enabling Ruchita to update articles, upload photos, and manage content with live server synchronization.

2. **3-Pillar Foundation**:
   - **01. REPORT**: Investigative reporting, ground dispatches, and Peace to Camera (PTC) video packages.
   - **02. CREATE**: Digital storytelling, visual explainers, carousel news, and social advocacy.
   - **03. COMMUNICATE**: Corporate communications, media strategy, PR campaigns, and brand voice.

3. **Curated Portfolios & Showcases**:
   - **The Hans India & National Bylines**: Field reports, policy dispatches, and public interest investigations.
   - **The Lit Scroll**: Group E academic journalism initiative from IIMC Dhenkanal (*"No Cap, Just Facts"*).
   - **Substack In-Depth**: Long-form essays, personal columns, and cultural commentary.
   - **Ethicly Journalism Assistant**: Interactive media ethics guidelines and copy polishing tool.

4. **Interactive Recommendations & Testimonials Hub**:
   - Allows editors, peers, and mentors to leave verified endorsements directly or import LinkedIn recommendations.

5. **Integrated AI Assistant**:
   - Powered by **Google Gemini 3.7 Flash** to auto-generate excerpts, structured takeaways, and metadata tags from pasted article drafts or URLs.

## 🚀 Local Development Setup

### Prerequisites
- Node.js 20+ installed
- npm or bun

### Installation & Run

```bash
# 1. Clone repository
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name

# 2. Install dependencies
npm install

# 3. Start development server (serves on http://localhost:3000)
npm run dev

# 4. Build for production
npm run build
npm start
```
